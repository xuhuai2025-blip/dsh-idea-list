# 灵感清单

DeepSeek Harness 原生侧边栏插件：标题＋详细内容＋自定义分类。通过语义化样式接口联动「风格工坊」，停用风格工坊后仍可独立使用。

## 使用

- 上方分别填写**标题**（必填，最多 80 字）和**具体内容**（可选，最多 30,000 字），选择分类后点击「记下想法」。Ctrl / ⌘ + Enter 也可保存；详情支持多行文本。
- 下方按分类分区展示紧凑卡片，**只显示标题与左侧复选框**。勾选方框直接完成／恢复，不会打开详情；点击标题弹出详情。在弹窗中编辑标题、完整内容、所属分类，或删除。
- 「管理分类」支持新增、重命名、删除自定义分类，不预置固定的工作／学习／研究分类。未选择分类的条目归入「未分类」。删除分类时，其条目只移入「未分类」，不会删除。
- 支持未完成／已完成／全部筛选，同时搜索标题和具体内容；没有匹配条目的分类不占位。
- 最近一次成功删除的条目可撤销，也可关闭撤销提示。弹窗支持 Esc、遮罩点击和关闭按钮；编辑未保存时关闭会询问是否放弃。
- 「导出备份」导出全部记录和分类的 JSON，不受筛选或搜索影响。目前不内置导入功能。

## 已有记录兼容

存储键继续使用 `dsh.local.idea.v1`，不会新建空清单或清空旧数据。旧版单段文本在内存中映射为：首个非空行作为标题（最多 80 字），**原始全文完整保留在具体内容中**，原 ID、时间、完成状态保留，归入「未分类」。初次读取不写盘；首次成功修改时保存为 version 2（含 items 与 categories）。异常或未知版本不覆盖，保存失败明确提示。

## 风格工坊联动

配色和原生字体直接继承。卡片保留风格工坊的纸纹、胶带、玻璃等材质接口，随所选主题变化，不复制主题状态。语义化接口：`data-stylelab-scope="inspiration"`（页面）、`data-stylelab-collection="notes"`（各分类卡片集合）、`data-stylelab-surface="note|composer|control"`（对应表面）。默认或停用风格工坊时回到基础样式。

## 数据范围

数据只保存在**当前浏览器、当前站点来源**的 localStorage，不上传、不跨设备同步。不同浏览器、桌面与网页端、不同端口或清理站点数据后，可能看不到原记录，请定期导出备份。切换聊天不会改变清单；插件停用／卸载不主动清空记录。输入草稿在插件存活期间跨面板切换保留，刷新或停用会丢失未保存草稿。

同源窗口通过 storage 事件同步；支持 Web Locks 时串行提交，减少多窗口写入冲突；无 Web Locks 时不承诺并发无冲突。每次写入读取最新数据，先保存成功再更新列表。

## 安装与开发

通过 DSH「插件 → 添加插件」安装发布包，或选择本插件的已构建目录。内部包名保留 `@local/dsh-idea`，侧栏名称为「灵感清单」。本插件是 MIT 授权的第三方插件，不属于宿主内置功能；宿主需兼容 `package.json` 中的 DSH 版本。

开发要求 Node.js >=22.14 和 pnpm 11。在插件根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm pack
```

构建与测试只用 Node.js 标准库，无需第三方运行时依赖或开发依赖。React 与原生 slots 由 DSH 提供，不打包另一份 React。锁文件仍保留以固定包管理器的依赖图。

`store.js` 是数据模型，`panel.js` 是界面源码，`dist/client.js` 是自包含浏览器产物；测试位于 `tests/`。构建相对于脚本定位文件，与工作目录和宿主 checkout 无关。`prepack` 自动重建并执行测试，发布白名单只包含运行文件、语言资源、图标与文档。

重新安装或重新构建后，通过插件管理器停用／启用插件，并刷新宿主页面；如宿主提示重启则按提示处理。没有源码构建 watcher，不承诺实时热更新。自动化测试不等同于宿主中的界面验收。
